# ETF Atlas

네이버 금융 ETF 목록을 운용사·시장·상품 유형별로 분석하는 한국어 HTML 대시보드입니다.

## 실행

Node.js 24 이상에서 별도 패키지 설치 없이 실행합니다.

```bash
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. `PORT` 환경변수로 포트를 변경할 수 있습니다. HTML 파일을 직접 열면 `/api/etfs` 서버가 없어 실시간 조회가 동작하지 않습니다.

```bash
npm test
npm run build
```

`public/index.html`은 화면, `public/styles.css`는 반응형 디자인, `public/app.js`는 상호작용, `public/domain.js`는 분류와 집계 로직입니다. `server/provider.mjs`는 네이버 API의 EUC-KR 응답을 디코딩하고 검증합니다. `server/worker.mjs`는 웹페이지와 API를 같은 출처에서 제공하므로 브라우저의 교차 출처 제한에 의존하지 않습니다. 빌드는 별도 의존성 없이 정적 파일을 포함한 Cloudflare Worker ESM `dist/server/index.js`를 생성합니다.

## 기능

- 시장 개요 / 운용사 / 시장 / 상품 유형별 분석 화면
- 이름·코드·운용사 검색과 운용사·시장·상품 복합 필터
- 시가총액·거래대금·단순 평균 등락률·시장 상승/하락 분포
- 그룹별 시가총액 차트 및 비중, 그룹별 상세 집계표
- 정렬·페이지 이동·20/50/100개 표시
- 브라우저에 저장되는 관심 ETF, 최대 4개 종목 비교, 종목 상세 정보
- 조회 조건 전체 결과 CSV 다운로드
- 30/60/120초 자동 갱신 및 수동 갱신, 갱신 중지, 오류·이전 데이터 상태 표시
- 데스크톱과 모바일 반응형, 키보드 접근 및 비교 대화상자

## 데이터 계약과 해석

출처: https://finance.naver.com/api/sise/etfItemList.nhn

HTTP GET, 인증 불필요, 페이지 구분 없는 전체 목록입니다. 검증 시 1,188개가 반환됐으며 종목 수는 실행 시마다 바뀔 수 있습니다. 배열 경로는 `result.etfItemList`이며 `resultCode=success`를 확인합니다.

| 필드 | 의미 / 단위 |
|---|---|
| itemcode / itemname | 종목코드 / 상품명 |
| etfTabCode | 1 국내 시장지수, 2 국내 업종·테마, 3 국내 파생, 4 해외 주식, 5 원자재, 6 채권, 7 기타 |
| nowVal / changeVal | 현재가 / 전일 대비, 원 |
| changeRate | 등락률, % |
| threeMonthEarnRate | 제공되는 3개월 수익률, %; 결측은 표시하지 않음 |
| nav | NAV, 원 |
| quant | 거래량, 주 |
| amonut | 거래대금, 백만원; 원천 API의 오탈자 필드명 유지 |
| marketSum | 시가총액, 억원; 순자산총액이 아님 |

API는 실제 거래시각을 제공하지 않습니다. 화면의 수신시각은 서버가 원천 데이터를 받은 시각이며 장중 실시간 체결시세를 보장하지 않습니다. 장 마감이나 휴장일에는 자동 갱신 후에도 동일한 값이 반환될 수 있습니다. 서버 캐시는 20초입니다. 일시적인 실패 때 15분 이내의 이전 데이터를 명시적으로 표시하며, 최초 수신 실패 시 샘플 데이터를 대신 보여주지 않습니다. 브라우저는 오류 발생 시 마지막 수신 데이터를 유지하고 경고합니다.

운용사 정보는 API에 없어 상품명 브랜드를 매핑합니다. 미등록 브랜드는 `(브랜드)`로 표시합니다. 매핑은 `MANAGERS`에서 관리하며 브랜드 변경 시 점검해야 합니다. 상품 유형은 상품명 키워드와 시장 분류를 이용해 **커버드콜 → 인버스 → 레버리지 → 금리·현금성 → 채권형 → 원자재형 → 배당형 → 주식·테마형 → 기타·혼합형** 순서로 배정하는 상호 배타적인 규칙 분류입니다. 공식 투자설명서의 분류가 아닙니다.

평균 등락률은 결측을 제외한 단순 평균이며, 비중의 분모는 현재 조회 결과의 시가총액 합계입니다. 괴리율은 `(현재가 / NAV - 1) * 100`으로 계산합니다. 원천 가격과 NAV의 시점 차이가 있을 수 있습니다. 분배금·총보수·추적오차·위험등급·과거 시계열·순유입은 제공되지 않으므로 생성하거나 추정하지 않습니다.

## 배포

`.openai/hosting.json`은 이 프로젝트의 비공개 사이트 식별자를 담습니다. `npm run build` 후 `dist/server/index.js`를 실행 가능한 Worker 환경에 배포할 수 있습니다. API와 정적 페이지를 한 서버에서 제공해야 합니다. 인증 토큰·비밀번호는 소스에 포함하지 않습니다.

관심 목록은 로컬 브라우저 저장소에만 저장되며 서버 사용자 데이터베이스를 사용하지 않습니다. 공식 네이버 서비스가 아니며, API 제공 방식 변경이나 제한 시 연결을 점검해야 합니다.
